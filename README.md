# SRTEV — Admin & Operation Center Dashboard

An interactive web-based administration panel built with **React** and **Vite** for managing an electric vehicle rental service (SRTEV). The application enables administrators and support staff to track reports, reply to customer issues, manage vehicles, monitor user activity, and handle system alerts in real time.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React 18+
* **Build Tool:** Vite
* **Styling:** CSS3 / Custom Modular CSS
* **HTTP Client:** Fetch API
* **Icons & UI:** Custom SVG Assets & Modular Components

---

## ✨ Features

* **Operation Center & Ticketing:**
  * View and filter customer & repairman issue reports (vehicle issues, payment errors, account problems, etc.).
  * Real-time search across tickets by ID, Email, or Vehicle ID.
  * Interactive modal dialogs for responding directly to user tickets via SMTP integration.
  * Automated periodic background sync for fresh report fetching.

* **Tabs & Category Filtering:**
  * Multi-level category filtering with custom checkbox dropdowns.
  * User vs. Repairman tab segregation.

* **Dashboard Navigation:**
  * Integrated sidebar navigation for Maps, Users, Vehicles, Challenges, and Operation Center.
